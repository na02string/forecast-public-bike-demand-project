# forecast_public_bike_demand_project
[따릉이 수요량 예측 프로젝트](https://itdatascience.tistory.com/61)

# 소개
서울시 공공자전거 서비스인 따릉이는 시민들의 교통·레저 수단으로 활발히 이용되고 있으며, 수요 예측을 통해 효율적인 자전거 재배치 전략 수립이 절실한 상황입니다.
본 프로젝트는 '통계적 기계학습' 수업의 프로젝트로 진행되었으며, 2022년 서울시 따릉이 데이터를 기반으로 시간대별·지역별 수요 예측 모델을 개발해 자전거의 부족/과잉 상태를 사전에 예측하고 재배치 전략 수립에 활용될 수 있도록 설계되었습니다.


# 요약
서울시 공공자전거 대여소 수요량 예측 프로젝트

## 1. 프로젝트 개요

- **프로젝트명**: 서울시 공공자전거 대여소 수요량 예측
- **진행 기간**: 2023.03 ~ 2023.05
- **역할**: 데이터 수집 및 전처리, 탐색적 데이터 분석(EDA), 모델링
- **목적**:
  - 서울시 공공자전거 '따릉이'의 대여소별 수요 예측을 통해 효율적인 자전거 재분배 및 운영 개선
  - 장소별, 시간대별 수요 패턴을 분석하여 자전거 거치율 최적화 및 이용자 만족도 향상

## 2. 데이터 수집 및 전처리

- **데이터 출처**:
  - [서울시 공공자전거 대여이력 정보 (2022년 1월~12월)](https://data.seoul.go.kr/dataList/OA-15182/F/1/datasetView.do)
  - [서울시 공공자전거 이용정보(시간대별)](https://data.seoul.go.kr/dataList/OA-15245/F/1/datasetView.do)
  - [서울특별시_시간별 (초)미세먼지](https://www.data.go.kr/data/15089266/fileData.do)
  - [따릉이 대여소 위치(폐쇄 포함)](https://github.com/vuski/SeoulBikeStationLocation/tree/main)
  - [서울시 공공자전거 대여소 정보](https://data.seoul.go.kr/dataList/OA-13252/F/1/datasetView.do)
  - 외부 데이터: [서울시 시간대별 날씨 정보는 외부 크롤링을 통해 추가 수집](https://freemeteo.co.uk/weather/seoul/history/daily-history/?gid=1835848&language=english&country=united-kingdom&date=2022-06-05)
 
    
- [**전처리 과정**:](https://github.com/na02string/forecast-public-bike-demand-project/blob/main/1_data_preparing.ipynb)
  - 날짜 및 시간 정보를 활용한 시간대별 데이터 정리
  - 날씨 및 미세먼지 데이터를 대여 이력 데이터와 병합
  - 날씨 데이터를 특정 기준에 따라 범주화(discomfort, windforce, 미세먼지, 초미세먼지 등)
  - 결측치 및 이상치 처리
  - datetime 변환 및 시간 관련 특성(hour, month, dayofweek 등) 추출

### 4. 모델 개발 및 평가

- **모델 선택**:
  - EDA를 통해 따릉이 수요는 기온·습도·미세먼지 등 외부 요인과 시간대별 패턴에 강한 영향을 받는다는 사실을 확인했습니다. 특히 출퇴근 시간대 수요 피크, 기온 상승 시 수요 증가, 미세먼지 농도 증가 시 수요 감소 등의 명확한 패턴이 존재했습니다.
  - 시계열적 흐름과 이전 시간 정보의 의존성을 반영하기 위해, 이번 프로젝트에서는 기존의 선형 회귀나 일반 MLP보다 시간 순서에 따른 수요 패턴을 학습하는 데 더 적합한 모델인 LSTM(Long Short-Term Memory) 모델을 사용하기로 결정했습니다. 

- **입력 피쳐 구성**:
    - 아래의 11개 변수를 입력값으로 사용했습니다.
        - 대여
        - 대여 이용거리
        - 대여 이용시간
        - 반납
        - 반납 이용거리
        - 반납 이용시간
        - 반납-대여 (자전거 부족 및 잉여 상태 지표)
        - 기온
        - 습도
        - 미세먼지(PM10)
        - 초미세먼지(PM2.5)
    - 시간 관련 변수(hour, dayofweek, is_holiday)는 전처리 및 EDA 단계에서는 유의미한 패턴을 보였으나, 실제 모델 학습에 적용했을 때 성능 향상이 크지 않아 최종 모델에서는 제외했습니다.
        - 성능 향상이 크지 않았던 이유로는 LSTM 모델이 이전 시간들의 데이터를 연속적으로 입력받아 학습하는 구조이기 때문인 것 같습니다. 현재 모델이 4시간치 데이터를 기반으로 다음 시간의 수요를 예측하게 되어 있는데, 이때 최근 몇 시간 동안의 대여 및 반납 패턴만 보고도 어느 정도 시간대를 유추할 수 있어서 시간 관련 변수의 필요성이 줄어든 것으로 보입니다.

- **모델 구조 및 학습 방식**
    - 모델 : LSTM
    - 입력 차원 : 11
    - Window Size : 4 (이전 4시간의 데이터를 기반으로 다음 시간 예측)
    - 출력 : 다음 한 시간의 `반납 - 대여` 값
    - 손실 함수 : MSELoss
    - 정규화: StandardScaler 사용
    - 최적화 알고리즘 : Adam
    - train/valid 분할 : train 90%, valid 10%
    - Early stopping 을 통해 과적합 방지

- **평가 방법 및 결과**
    - 대여소별 최근 1주일 수요 데이터를 기준으로 평가를 진행했고, 예측값과 실제값(`반납-대여`)의 시간별 시계열 그래프를 비교해 성능을 시각적으로 평가했습니다.

# 아쉬운 점
- 전체 대여소에 대한 예측 및 최적 경로 설계 미완성
    - 시간 제약으로 인해 모든 대여소를 대상으로 예측을 진행하고, 그 결과를 기반으로 최적 경로 탐색 알고리즘을 적용해보지 못한게 아쉽습니다. Traveling Salesman Problem(TSP)과 같은 최적 경로 탐색 알고리즘을 적용해, 예측된 수요를 기반으로 자전거 재배치 경로를 최적화하는 것도 흥미로운 확장 방향이 될 것 같습니다.
- 시간 관련 변수 미반영
    - `hour`, `dayofweek`, `is_holiday`와 같은 시간 정보가 수요에 영향을 미친다는 게 EDA를 통해 확인되었지만, 실제 모델에 반영했을 때 성능 향상이 크지 않아 최종적으로 제외했습니다. 결과적으로 명시적 시간 조건 반영이 부족했던 점은 아쉽습니다.
- 공간적 정보 미활용
    - 현재 모델은 대여소 간 거리, 인접성, 유사 지역군과 같은 공간적 특성을 고려하지 못 했기 때문에, 수요가 인접 대여소에 미치는 영향을 반영하는 건 한계가 있을 것 같습니다.
    - 또한 LSTM 모델은 시간적 흐름은 잘 반영할 수 있었지만, 공간적 요소까지 통합적으로 학습하기에는 한계가 있습니다. 이후에는 Transformer 기반 시계열 예측 모델이나, GNN(Graph Neural Network) 구조를 활용하여 시간과 공간 정보를 함께 학습하는 방식으로 확장해보는 것도 유의미한 발전 방향이 될 것같다는 생각이 듭니다.
